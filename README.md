# Python Data Analysis

A collection of Python data analysis notebooks and utilities covering:

- **datetime_handling** — working with dates and times in Python
- **defaultdict_usage** — practical use cases for `collections.defaultdict`
- **itertools_usage** — itertools patterns for efficient iteration
- **numpy_performance** — NumPy performance tips and comparisons
- **to_improve_readability** — code readability best practices
- **tuple_unpacking** — idiomatic tuple unpacking patterns

## Setup

Requires Python 3.11+. Dependencies are managed with [uv](https://github.com/astral-sh/uv).

```bash
uv sync
```
